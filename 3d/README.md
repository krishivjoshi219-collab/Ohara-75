# Ohara-75 3D printed case

Two parts:

- `Ohara-75-Base-Tray.stl` — back/base tray. **This is the modified one.** The USB-C cable pass-through is already cut.
- `Ohara-75-Lid.stl` — front lid/bezel.

## USB-C pass-through

The cutout is a U-shaped slot through the 2.2mm front wall:

- center: `x = 140.75mm`
- width: `14mm`
- height: `8mm`
- bottom of slot: `z = 0.5mm`
- top of slot: `z = 8.5mm`

It lines up with the USB-C connector on the PCB. The slot is closed at the top so the lid still sits flat.

## Print notes

- Print the base with the opening facing up, no supports needed for the walls.
- The lid is a thin plate; print it flat on the bed.
- Use 0.2mm layers or finer.
- 3 or 4 walls is good for the base.
- Check the USB-C hole with a real cable before you assemble everything. If your cable overmold is huge, scale the hole in CAD or use a bigger cable. lol.
